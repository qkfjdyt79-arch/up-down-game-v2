# 🎮 Up-Down Game v2.0+ (Global Edition)

A Python-based terminal number guessing game built for a global audience.

## 🚀 Key Features
- **Difficulty Modes**: Easy (`1 to 50`), Normal (`1 to 100`)
- **Error Handling**: Input validation for non-numeric input and out-of-bounds options
- **Global UI**: Fully localized user interface and warning messages in English
- **Safe Exit**: Enter anytime to quit, with exit protection (`input()`) to prevent instant terminal closure

## 🛠️ Tech Stack & Concepts
- Python 3
- `while` loops, exception handling (`try-except`), f-strings, `.strip()`

## 📝 Learning Points
- Debugged syntax errors (`SyntaxError`) and escape sequence formatting (`\n`) independently.
- Transitioned from code dependency to fully understanding and mastering program logic.
